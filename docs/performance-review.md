### Red flags

- **[G] Version-coupled drawer integration:** `src/components/ui/drawer.tsx:8` nests a controlled Radix root because installed Vaul 1.1.2 does not forward `modal`; `src/components/PlacesExplorer.tsx:343` suppresses pointer-out during captured drag. Both address reproduced failures, but remain upgrade-sensitive. Keep these localized and regression-check focus, cancellation, scrolling, and lightbox return after dependency changes; do not spread the workaround into other components. Contract: DESIGN.md's primitive ownership and accessible interaction rules.
- **[D] Engine startup cost:** native gesture ownership adds roughly485KB gzip of lazy engine/worker/geography assets. It is isolated to the explorer, but startup on slower mobile connections must be measured on hardware before release.

### Recommendation

The migration fixes the bespoke gesture ownership and has production/browser evidence above. The engine replacement is justified by the reported mobile failures, and its added engine/worker cost is explicit. Hosted worker/shared-module/GeoJSON delivery is included in the final PR verification pass. Defer broad rewrites, unrelated dependency churn and deeper contact/photo-pipeline audits; rerun those with explicit paths because this review covers only 37% of the broader change. Physical iPhone/Safari behavior and field Core Web Vitals remain unverified unless separately recorded.
